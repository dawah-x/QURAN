Musnad Ahmad — Bengali machine-translation provenance and licence note
=====================================================================

What this is
------------
DAWAH X ships the complete Arabic text of Musnad Ahmad (26,363 records) from
elyabany/Hadith, verbatim. v12 adds a Bengali field for every one of those
26,363 records. That Bengali text is an OFFLINE, AUTOMATIC (machine) translation
generated at build time from the Arabic, not a published, scholarly, or
editorially reviewed Bengali edition. It is labelled in the app as
«স্বয়ংক্রিয় যান্ত্রিক অনুবাদ». The Arabic remains the authoritative text; users
must consult the Arabic and a qualified scholar for meaning or legal rulings.

Translation pipeline (build time only; no runtime network)
---------------------------------------------------------
Arabic -> English -> Bengali, because the Argos package index provides
`ar_en` and `en_bn` packages but no direct `ar_bn` package. Generation runs in
the manual `.github/workflows/generate-ahmad-bn.yml` workflow using
CTranslate2 + SentencePiece directly against locally downloaded model packages.
The web app does NOT call this workflow, any translation API, fetch(), XHR,
CDN, or external service. The resulting text is committed as
`data/ahmad_bn_argos.json.gz` and rendered from local lazy JS shards.

Quality and limits
------------------
Neural machine translation of classical Arabic hadith through an English pivot
can be inaccurate, incomplete, or doctrinally misleading. It is provided only
as a reading aid because no clean, redistributable, complete Bengali Musnad
Ahmad edition was available. Do not rely on it for fatwa, creed, or exact
wording. No hadith text, number, grade, chapter, narrator, or Arabic letter was
invented: Arabic and all other source fields remain verbatim, and the Bengali
field is clearly marked as machine output. The repository's verifier checks
that all 26,363 Bengali fields are present and contain Bengali script, but it
cannot certify semantic or scholarly correctness.
