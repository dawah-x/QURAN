# DAWAH X — আল-কুরআন

একটি সম্পূর্ণ স্ট্যাটিক, নির্ভরতাহীন কুরআন পাঠক — **উসমানী আরবি পাঠ + ড. আবূ বকর মুহাম্মাদ যাকারিয়ার সম্পূর্ণ বাংলা অনুবাদ ও তাফসীর/টীকা**।

দুটি উৎস থেকে বানানো:

| উৎস | কী পাওয়া গেছে |
|---|---|
| `Hafs_20.zip` ([QuranEnc.com](https://quranenc.com/en/home/api)) | **KFGQPC HAFS Uthmanic Script** ফন্ট + `Quran_text.csv` (হাফস কিরাআতের উসমানী লিপি, ১১৪ সূরা / ৬,২৩৬ আয়াত) |
| [quranenc.com/bn/browse/bengali_zakaria](https://quranenc.com/bn/browse/bengali_zakaria) | **Bengali Translation - Abu Bakr Zakaria** (`bengali_zakaria` **v1.1.1**) — ৬,২৩৬টি আয়াতের বাংলা অনুবাদ + **৩,৬০৮টি তাফসীর/টীকা** |

কোনো বিল্ড স্টেপ, npm প্যাকেজ, CDN বা রানটাইম API নেই — ফাইলগুলো যেমন আছে তেমনই Netlify / GitHub Pages / `python3 -m http.server`-এ চলে, অফলাইনেও।

## চালানো

```bash
python3 -m http.server 8888          # http://localhost:8888
```

`index.html` ডকুমেন্ট রুটে রাখুন। `file://` থেকেও খোলে — সব ডেটা `<script>` হিসেবে লোড হয়, কোনো `fetch()` নেই। তাফসীর ১১৪টি ছোট ফাইলে ভাগ করা আছে এবং **প্রয়োজন হলেই (lazy)** লোড হয়, তাই প্রথম পাতা হালকা থাকে।

```
  quran-data.js             আরবি পাঠ (CSV → JS)
  bn-translation.js         ৬,২৩৬ বাংলা অনুবাদ + "টীকা আছে কি" তালিকা
  tafsir/1.js … 114.js      ৩,৬০৮ তাফসীর/টীকা, সূরাভিত্তিক lazy লোড
  Hafs_20.woff2 / .ttf      KFGQPC HAFS Uthmanic Script

tools/
  build-data.py             CSV → assets/quran-data.js
  build-bangla.py           স্ন্যাপশট → bn-translation.js + assets/tafsir/*.js
CREDITS.md                  উৎস, সংস্করণ, লাইসেন্স ও শর্তাবলি
Hafs_20.zip                 মূল আর্কাইভ (অক্ষত)
netlify.toml                স্ট্যাটিক publish + অ্যাসেট ক্যাশ হেডার
```

পুনর্নির্মাণ:

```bash
python3 tools/build-data.py     # আরবি পাঠ
python3 tools/build-bangla.py   # বাংলা অনুবাদ + তাফসীর (SHA-256 যাচাইসহ)
```

## ডেটা ও নির্ভুলতা

- আরবি পাঠ `data/Quran_text.csv`-এর `uthmani` কলাম থেকে **হুবহু**; ১ নং সূরার ১ নং আয়াত থেকেই বিসমিল্লাহ নেওয়া হয়, ৯ নং সূরা ছাড়া বাকি সূরার শুরুতে বিসমিল্লাহ আলাদাভাবে দেখানো হয়।
- বাংলা অনুবাদ ও টীকা **অপরিবর্তিত** (`bengali_zakaria` v1.1.1)। শুধু রেন্ডারিংয়ের জন্য টীকার `<b>` মার্কআপ ও নতুন লাইনকে নিরাপদ HTML-এ রূপ দেওয়া হয়েছে — লেখা বদলানো হয়নি। স্ন্যাপশটের SHA-256: `dc09d6ed6fbcc943d25599b55685b3d536618accfff9f0ef731895a837d10936`।
- **এই «তাফসীর» হলো ঐ অনুবাদের সাথে প্রকাশিত বিস্তারিত টীকা/ভাষ্য** (QuranEnc-এ «টিকা প্রদর্শন»), কোনো আলাদা তাফসীর গ্রন্থ নয়। ৩,৬০৮টি আয়াত-টীকা, মোট ~৪৩ লক্ষ অক্ষর।
- সূরার নাম/উচ্চারণ হাতে-লেখা তালিকা; আয়াত সংখ্যা CSV থেকে গণনা করা হয়।
- অনুবাদের পুনঃপ্রকাশে [QuranEnc.com-এর ৭টি শর্ত](https://quranenc.com/en/home/api) মেনে চলা হয়েছে — ক্রেডিট, সংস্করণ, অপরিবর্তিত লেখা ও কোনো বিজ্ঞাপন নেই। বিস্তারিত: [CREDITS.md](CREDITS.md)।
