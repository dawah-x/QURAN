## চালানো

```bash
python3 -m http.server 8888          # http://localhost:8888
```

অথবা `index.html` সরাসরি `file://` থেকে খুলুন — **কোনো বিল্ড, npm, CDN বা রানটাইম API নেই**। সব ডেটা `<script>` হিসেবে লোড হয় (`fetch()` নেই), তাই অফলাইনে ও কিয়স্ক ডিভাইসেও চলে। PWA service worker শুধু `https://` / `localhost`-এ কাজ করে; `file://`-এ সাইট আগের মতোই চলে।

### প্রথম লোড কতটা হালকা

| ফাইল | কখন লোড | আকার |
|---|---|---|
| `assets/quran-data.js` | প্রথম পাতা | ১.৩ MB (আরবি) |
| `assets/bn-index.js` | প্রথম পাতা | **৩৫ KB** (meta + টীকা-বিটম্যাপ) |
| `assets/quran-meta.js` | প্রথম পাতা | ১১ KB |
| `assets/bn/<sura>.js` | ওই সূরা খুললে | ~১–১৭০ KB |
| `assets/tafsir/<sura>.js` | তাফসীর চাইলে | ~১–১,০০০ KB |
| `assets/bn-translation.js` | **প্রথম সার্চে একবার** | ২.২ MB (একটিই রিকোয়েস্ট) |

`/assets/*`-এ `?v=8` cache-busting, `index.html`/`sw.js` `must-revalidate` — নতুন ডিপ্লয়ে পুরনো ক্যাশ আটকে থাকে না। তবুও প্রয়োজনে **hard refresh** (Ctrl/Cmd+Shift+R)।

## পুনর্নির্মাণ ও যাচাই

```bash
python3 tools/build-data.py      # আরবি CSV → quran-data.js
python3 tools/build-bangla.py    # SHA-256 যাচাই → bn-index, bn/*, bn-translation, tafsir/*
python3 tools/build-meta.py      # HafsLists → quran-meta.js
python3 tools/build-font.py      # → NotoSansBengali.woff2   (fonttools + brotli)
python3 tools/build-icons.py     # → icons/*                (pillow)
python3 tools/verify.py          # চেকসাম, গণনা, ২৩৫টি JS-এর syntax, লাইসেন্স, PWA — ৪৬ চেক
cd tests && npm install && npm test   # ৬০+ jsdom চেক
```

`build-font.py` / `build-icons.py` শুধু **বিল্ড-টাইম** ডিপেন্ডেন্সি; তাদের আউটপুট কমিট করা আছে, তাই সাইট চালাতে কিছু ইনস্টল করতে হয় না। CI-তে ডেটা-জেনারেটরগুলো পুনরায় চালিয়ে `git diff --exit-code` দিয়ে নির্ধারণযোগ্যতা (determinism) যাচাই করা হয়।

- ফুটারের ছোট **«ক্রেডিট»** লিংক, রিডারের `source-note`, মডাল, কপি-টেক্সট ও `CREDITS.md`-তে প্রকাশক + উৎস + **v1.1.1**; কোনো বিজ্ঞাপন/ট্র্যাকিং নেই। [৭টি শর্ত](https://quranenc.com/en/home/api) মেনে চলা হয়েছে।
