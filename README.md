# DAWAH X — আল-কুরআন

`Hafs_20.zip` থেকে বানানো একটি সম্পূর্ণ স্ট্যাটিক কুরআন পাঠক (Quran reader)। জিপের ভেতরে ছিল **KFGQPC HAFS Uthmanic Script** ফন্ট (`Hafs_20.woff2` / `Hafs_20.ttf`) এবং হাফস কিরাআতের **উসমানী লিপির সম্পূর্ণ কুরআন** (`Quran_text.csv`: ১১৪ সূরা, ৬,২৩৬ আয়াত)। দুটোই কাজে লাগিয়ে এই সাইটটি তৈরি করা হয়েছে।

কোনো বিল্ড স্টেপ নেই, কোনো npm প্যাকেজ নেই, কোনো বাহ্যিক API বা CDN নেই — ফাইলগুলো যেমন আছে তেমনই যেকোনো স্ট্যাটিক হোস্টে (Netlify, GitHub Pages, `python3 -m http.server`) চলে।

## ফিচার

| | |

| ★ **বুকমার্ক** | যেকোনো আয়াত সংরক্ষণ, আলাদা তালিকা, `localStorage`-এ সেভ |

| 🕰 **অন্যান্য** | আজকের আয়াত, এলোমেলো আয়াত, “পড়া চালিয়ে যান”, ঢাকার ঘড়ি, কীবোর্ড শর্টকাট (`/`, `←`, `→`, `Esc`), প্রিন্ট স্টাইল |

## চালানো

```bash
python3 -m http.server 8888          # http://localhost:8888
# অথবা: npx serve . / netlify dev / যেকোনো স্ট্যাটিক সার্ভার
```

`index.html` ডকুমেন্ট রুটে রাখুন। ফাইলগুলো `file://` থেকেও খোলে (সব ডেটা `<script>` হিসেবে লোড হয়, `fetch()` ব্যবহার করা হয়নি)।

## গঠন

```
index.html                  একক পেজ অ্যাপ (hash routing)
favicon.svg                 আট-কোণা জ্যামিতিক মার্ক
assets/
  style.css                 সব স্টাইল (dark + light থিম, responsive, print)
  app.js                    রাউটিং, রেন্ডার, সার্চ, বুকমার্ক, কীবোর্ড
  surahs.js                 ১১৪ সূরার নাম (আরবি / ইংরেজি / বাংলা)
  quran-data.js             CSV থেকে জেনারেট করা window.QURAN
  Hafs_20.woff2             KFGQPC HAFS Uthmanic Script (primary)
  Hafs_20.ttf               একই ফন্টের fallback
data/
  Quran_text.csv            মূল উৎস ডেটা (id, sura, aya, uthmani)
tools/
  build-data.py             CSV → assets/quran-data.js পুনর্নির্মাণ
Hafs_20.zip                 ব্যবহারকারীর দেওয়া মূল আর্কাইভ (অক্ষত)
netlify.toml                স্ট্যাটিক publish + অ্যাসেট ক্যাশ হেডার
```

CSV বদলালে ডেটা ফাইল আপডেট করতে:

```bash
python3 tools/build-data.py
```

## ডেটা ও নির্ভুলতা

- আয়াতের পাঠ `data/Quran_text.csv`-এর `uthmani` কলাম থেকে **হুবহু** নেওয়া; কোনো পরিবর্তন বা পুনর্লিখন করা হয়নি। ১ নং সূরার ১ নং আয়াত থেকেই বিসমিল্লাহ নেওয়া হয়, এবং ৯ নং সূরা ছাড়া বাকি সূরার শুরুতে বিসমিল্লাহ আলাদাভাবে দেখানো হয়।
- ফন্ট `Hafs_20.zip` থেকে নেওয়া **KFGQPC HAFS Uthmanic Script** (unitsPerEm 2048, বেশ উঁচু লাইন মেট্রিক্স — তাই `line-height` ২.১+ রাখা হয়েছে)।
- সূরার নাম/উচ্চারণ একটি হাতে-লেখা তালিকা; আয়াত সংখ্যা সরাসরি CSV থেকে গণনা করা হয়। প্রকাশনার আগে নামগুলো যাচাই করে নেওয়া ভালো।
- এই সাইটে কোনো অনুবাদ, তাফসির বা অডিও নেই — শুধু আরবি পাঠ। ফন্ট ও পাঠের ব্যবহার-সংক্রান্ত শর্তাবলি মূল সংস্থার (King Fahd Quran Printing Complex / ডেটা সরবরাহকারী) নীতিমালা অনুযায়ী প্রযোজ্য।
